## 0. 系統分層與角色

依賴方向是單向的 **`ui → mode → shape`**：

| 層    | 類別                                                                           | 職責                                                                     |
| ----- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| ui    | `Main`                                                                       | 程式進入點                                                               |
| ui    | `UMLEditor`                                                                  | 主視窗：放按鈕/選單（含工具列圖示的讀取）、管理按鈕高亮、標籤對話框      |
| ui    | `Canvas`                                                                     | 畫布：持有所有圖形、分派滑鼠事件、繪圖、管理 z-order 與模式、群組/解群組 |
| ui    | `ModeChangeListener`                                                         | 模式變更事件介面（Observer 契約）                                        |
| ui    | `DiagramFileIO`                                                              | 存檔 / 讀檔（Java 序列化＋白名單）與匯出 PNG，不含 UI 邏輯               |
| mode  | `Mode`（抽象）→ `SelectMode` / `CreateObjectMode` / `CreateLinkMode`  | 「目前這個工具收到滑鼠事件時做什麼」（State Pattern）                    |
| shape | `Shape`（抽象）→ `BasicObject` / `CompositeObject` / `ConnectionLine` | 畫布上的圖形（Composite Pattern）                                        |
| shape | `Port`                                                                       | 圖形邊界上的控制點                                                       |
| shape | `ShapeFactory`（抽象）→ `RectFactory` / `OvalFactory` / `ClassFactory`  | 工廠方法模式：建立 BasicObject                                           |
| shape | `ObjectType` / `LinkType`（enum）                                          | 型別安全的類型標記                                                       |

## 1. 程式啟動流程（main → 畫面出現）

### 1.1 進入點 `Main.main()`

```
JVM → Main.main(args)
  → SwingUtilities.invokeLater( lambda )   // 不立刻執行，排進 EDT（事件分派執行緒）待辦
```

EDT 有空時執行：

```
→ new UMLEditor()     // 在記憶體中組裝整個視窗（見 1.2）
→ .setVisible(true)   // 推上螢幕並第一次繪製（見 1.6）
```

### 1.2 `new UMLEditor()` 建構子逐步

```
 1. setTitle / setSize(800,600) / setDefaultCloseOperation / setLayout(BorderLayout)
 2. canvas = new Canvas()                              // ★ 見 1.3
 3. canvas.setModeChangeListener(this::highlightActiveButton)   // ★ 登記事件監聽（先登記，之後才會被觸發）
 4. add(canvas, CENTER)
 5. toolPanel = new JPanel(GridLayout(0,1))             // 0 = 列數依按鈕數量自動決定
 6. selectMode = new SelectMode(canvas)                // ★ 先建好 Select，留參考當預設
 7. addModeButton ×8                                   // ★ 見 1.4
 8. add(toolPanel, WEST)
 9. 建立選單，各自登記 actionListener（每個項目只登記一次）
      File：Open（Ctrl+O）/ Save（Ctrl+S）/ Export PNG（Ctrl+E）
      Edit：Group / Ungroup / Label / Delete（Delete 鍵）
      // 快捷鍵用 setAccelerator 掛在選單上，主視窗有焦點就有效
10. canvas.setDefaultMode(selectMode)                  // ★★ 指定預設模式並觸發第一次事件（見 1.5）
```

### 1.3 `new Canvas()` 建構子

```
→ setBackground(WHITE)
→ 建立匿名 MouseAdapter ma：
      mousePressed/ Dragged/ Released/ Moved(e) → currentMode.mouseXxx(e)
→ addMouseListener(ma) / addMouseMotionListener(ma)
```

重點：Canvas 不判斷滑鼠要做什麼，只把事件「盲目」轉交 `currentMode`（State Pattern）。

### 1.4 `addModeButton(panel, name, iconName, [iconSize,] mode)`（呼叫 8 次）

```
→ createBaseButton(name)                 // 建 JButton + 樣式（白底黑字、淺灰細框）
→ loadIcon(iconName, iconSize)           // 讀 icon/ 下的圖示：找副檔名 → 裁留白 → 等比例縮放 → 補白底
      → 成功：btn.setIcon(icon)、文字移到 Tooltip
      → 失敗（找不到檔案）：維持文字按鈕，印出警告
→ modeButtons.put(mode, btn)             // ★ 記「模式→按鈕」對照表
→ btn.addActionListener(e -> canvas.setCurrentMode(mode))   // 只登記
→ panel.add(btn)
```

8 顆按鈕對應的模式：Select、`CreateLinkMode×4`（ASSOCIATION/GENERALIZATION/COMPOSITION/DEPENDENCY）、`CreateObjectMode(ClassFactory)`、`CreateObjectMode(RectFactory)`、`CreateObjectMode(OvalFactory)`。

`addModeButton` 有兩個多載版本：不傳 `iconSize` 時圖案用預設的 `ICON_SIZE`（40px）；Select 的游標是實心塊狀，另外傳入較小的 `SELECT_ICON_SIZE`（22px）。

### 1.5 `canvas.setDefaultMode(selectMode)` —— 啟動最關鍵一步

```
→ defaultMode = selectMode
→ setCurrentMode(selectMode)
      → currentMode = selectMode
      → modeListener.onModeChanged(selectMode)            // ★ 事件發射
            → UMLEditor.highlightActiveButton(selectMode)
                  → 所有按鈕設淺灰細框 → Select 按鈕設黑色粗框
```

結果：建構子結束時 `currentMode = SelectMode`，Select 按鈕高亮。

### 1.6 `setVisible(true)` 與第一次繪製

```
→ 視窗顯示 → EDT 自動呼叫 paintComponent(g)
      → super.paintComponent(g)（清白底）
      → drawAllShapes(g)：shapes 是空的 → 兩輪都不畫
      → currentMode.draw(g)（SelectMode：selectionBox=null → 不畫）
```

初始畫面：左側 8 顆圖示按鈕（Select 高亮）、上方選單、空白畫布。

### 啟動呼叫序列（總表）

```
main → invokeLater →(EDT)
  ├─ new UMLEditor()
  │   ├─ new Canvas()（安裝 MouseAdapter）
  │   ├─ setModeChangeListener(this::highlightActiveButton)
  │   ├─ new SelectMode(canvas)
  │   ├─ addModeButton ×8（建按鈕＋讀圖示＋對照表＋new 各模式/工廠）
  │   ├─ 建選單
  │   └─ setDefaultMode → setCurrentMode → onModeChanged → highlightActiveButton（Select 換黑色粗框）
  └─ setVisible(true) → paintComponent（空畫布）
```

## 2. 繪製機制 paintComponent

```
paintComponent(g)
  → super.paintComponent(g)              // 清空塗背景
  → drawAllShapes(g)
        → 第一輪 for (Shape s : shapes) s.draw(g)         // 本體：依清單順序，越前面越底層（連線線身在最底）
        → 第二輪 for (Shape s : shapes) s.drawOverlay(g)  // 前景層：連線的箭頭，畫在所有物件之上
  → currentMode.draw(g)                  // 最後畫暫時性 UI（選取框/預覽框/預覽線）
```

- **z-order = 清單順序**，不必每幀排序。
- **連線分兩層畫**：線身（`draw`）在物件底下，箭頭（`drawOverlay`）在物件上面。箭頭尖端落在物件邊緣的 Port 上，斜向靠近時有一半會在物件內部，若跟線身一起畫在底層就會被物件蓋掉。
- 模式的 `draw` 永遠最後，所以選取框/預覽線一定在最上層。
- 匯出 PNG 的 `Canvas.renderToImage()` 也呼叫同一個 `drawAllShapes`，螢幕與圖片畫出來的結果一致（見 4.J）。

## 3. 滑鼠事件如何被分派（State Pattern）

```
使用者動作 → Swing → Canvas.MouseAdapter → currentMode.mouseXxx(e)
```

`currentMode` 是哪個模式就執行哪個版本。**換工具按鈕＝換 currentMode**，行為跟著變。

### 4.A 建立物件（Rect / Oval / Class）

**功能說明**：在畫布上拖曳出一個矩形、橢圓，或 UML 類別（分成名稱 / 屬性 / 方法三格的矩形）。

**前置條件**：點過「Rect」、「Oval」或「Class」按鈕，使 `currentMode` 變成對應的 `CreateObjectMode`。

**主流程（呼叫順序）**

```
① 點「Rect」按鈕
   btn.actionListener → canvas.setCurrentMode(rectMode)
        → currentMode = rectMode
        → onModeChanged → highlightActiveButton（Rect 換黑色粗框、其餘淺灰細框）

② 在畫布上按下左鍵   MouseAdapter.mousePressed → CreateObjectMode.mousePressed(e)
        → startPoint = e.getPoint()
        → previewBox = new Rectangle(startPoint)         // 0×0 的預覽框種子

③ 拖曳       mouseDragged(e)
        → x=min(起點x,現在x); y=min(...); w=abs(...); h=abs(...)   // 子功能①：支援反向拖曳
        → previewBox.setBounds(x,y,w,h)
        → canvas.repaint() → paintComponent → CreateObjectMode.draw(g)
              → g.setColor(DARK_GRAY)
              → factory.drawPreview(g, previewBox)        // 子功能②：RectFactory畫矩形 / OvalFactory畫橢圓 / ClassFactory畫分三格的矩形

④ 放開左鍵   mouseReleased(e)
        → finalW=previewBox.width; finalH=previewBox.height
        → if (finalW<10 || finalH<10) finalW=finalH=80     // 子功能③：只點一下沒拖曳 → 預設 80×80
        → obj = factory.orderShape(previewBox.x, previewBox.y, finalW, finalH)   // ★ 工廠方法模式
              → createShape(x,y)                          // RectFactory → new BasicObject(x,y,RECT)；ClassFactory → CLASS
                    → BasicObject 建構子：
                          portCount = (OVAL?4:8)           // 子功能④：Rect、Class 8 個 Port，Oval 4 個
                          建立 Port(this)×portCount → updatePorts()
              → obj.setBounds(x,y,finalW,finalH) → updatePorts()
        → canvas.addShape(obj)                            // isBackgroundLayer()=false → shapes 尾端（最上層）
        → startPoint=null; previewBox=null; canvas.repaint()
        → canvas.returnToDefaultMode()                    // ★ 自動回 Select（見 5.1）
```

**替代流程**

- **Alt A.1**：拖曳距離極小（<10px）→ 不會做出超小圖形，改用預設 80×80。

**涉及函式**：`UMLEditor.addModeButton` 的 listener、`Canvas.setCurrentMode`、`CreateObjectMode.mousePressed/mouseDragged/mouseReleased/draw`、`ShapeFactory.orderShape`、`RectFactory/OvalFactory/ClassFactory.createShape/drawPreview`、`BasicObject` 建構子/`setBounds`/`updatePorts`、`Canvas.addShape/returnToDefaultMode`。

### 4.B 建立連線（Association / Generalization / Composition / Dependency）

**功能說明**：從一個物件的 Port 拉一條線到另一個物件的 Port，依類型畫不同箭頭。

**前置條件**：點過 Association/Generalization/Composition/Dependency，`currentMode` 為帶對應 `LinkType` 的 `CreateLinkMode`。

**主流程（呼叫順序）**

```
① 點「Association」按鈕 → setCurrentMode(linkMode) → 高亮

② 滑鼠移動（找得到 Port）   CreateLinkMode.mouseMoved(e)
        → target = canvas.getTopShapeAt(point)
        → 若 target 改變：舊的 setHovered(false)、新的 setHovered(true)
        → canvas.repaint()                                // 子功能①：移到圖形上就亮出它的 Port，看得到可連接點

③ 在某 Port 上按下   mousePressed(e)
        → startPort = null
        → for 每個 shape：port = s.getPortAt(p)
              若命中 → startPort=port; sourceShape=s; startX/Y=port座標; currentX/Y=startX/Y; break

④ 拖曳（預覽線跟著跑）   mouseDragged(e)
        → 若 startPort==null → return                      // 替代流程 Alt B.1
        → currentX/Y = 滑鼠座標
        → 先把所有 shape setHovered(false)                 // 子功能②：避免殘留亮著的 Port
        → target = canvas.getTopShapeAt(point)
        → 若 target!=null 且 target!=sourceShape → target.setHovered(true)
        → canvas.repaint() → CreateLinkMode.draw(g)
              → drawLine(startX,startY,currentX,currentY)  // 黑色預覽線

⑤ 在另一個 Port 上放開   mouseReleased(e)
        → 若 startPort==null → return
        → for 每個 shape：getPortAt(releasePoint) → endPort
        → 若 endPort!=null 且 startPort.getParent()!=endPort.getParent()   // 子功能③：不能自己連自己
              → new ConnectionLine(startPort, endPort, linkType)
              → canvas.addShape(line)                      // isBackgroundLayer()=true → shapes 最前面（最底層）
              → canvas.repaint()
        → startPort=null; 所有 shape setHovered(false); hoveredShape=null; canvas.repaint()
        → canvas.returnToDefaultMode()                     // 回 Select
```

**子功能④：四種連線（`ConnectionLine.drawArrow` 內 `switch(linkType)`）**

- `ASSOCIATION` → 畫 V 型兩條線
- `GENERALIZATION` → 空心三角形（白底＋框線）
- `COMPOSITION` → 實心菱形
- `DEPENDENCY` → 箭頭與 ASSOCIATION 相同（`case` 貫穿共用同一段程式），差別在**線身是虛線**：`ConnectionLine.draw` 遇到 DEPENDENCY 時改用虛線筆觸 `DASHED_STROKE`（選取時用粗虛線）；箭頭仍是實線，避免短短的翅膀被虛線切碎

箭頭由 `ConnectionLine.drawOverlay` 呼叫 `drawArrow`，在第二輪（前景層）才畫，所以不會被物件遮住；線身由 `ConnectionLine.draw` 在第一輪畫（見第 2 節）。兩者都先呼叫 `applyLineStyle()` 設定顏色與筆觸，樣式永遠一致。

**子功能⑤：連線自動跟著 Port 走**：`ConnectionLine.draw / drawOverlay` 每次都即時讀取 `startPort.getX()/getY()`、`endPort...`，所以物件移動後連線會自動跟著動，不需額外更新。

**替代流程**

- **Alt B.1**：起點不在任何 Port（點空白）→ `startPort` 保持 null → 後續 drag/release 全部直接 return，不建立任何東西。
- **Alt B.2**：終點不在 Port，或起終點屬同一個圖形 → 不建立連線。

**涉及函式**：`CreateLinkMode.mouseMoved/mousePressed/mouseDragged/mouseReleased/draw`、`Canvas.getTopShapeAt`、`Shape.getPortAt`、`Port.contains`、`ConnectionLine` 建構子/`draw`/`drawOverlay`/`applyLineStyle`/`drawArrow`、`Canvas.addShape`（背景層分流）/`returnToDefaultMode`。

### 4.C 選取 / 取消選取（單選＋框選）

**功能說明**：點選單一物件或連線、或拖出方框框選多個；點空白取消選取。被選取/懸停的物件會顯示 Port，連線則以藍色高亮。

**前置條件**：`currentMode` 為 `SelectMode`（預設）。

**主流程（呼叫順序）**

```
滑鼠移動（懸停）   SelectMode.mouseMoved(e)
   → target = canvas.getTopShapeAt(point)
   → 若 target 改變：舊的 setHovered(false)、新的 setHovered(true) → repaint   // 子功能①：懸停顯示 Port

按下   SelectMode.mousePressed(e)
  (A) 先檢查是否點到「已選取/懸停圖形」的 Port → 命中則進入縮放（見 4.F），return
  (B) 否則 draggedShape = canvas.getTopShapeAt(startPoint)
        ├─ draggedShape != null 且「尚未被選取」：
        │     canvas.clearSelection() → draggedShape.setSelected(true) → canvas.floatToFront(draggedShape)   // 子功能②：選取＋浮到最上層
        ├─ draggedShape != null 且「已被選取」（單選/多選）：保留選取，準備整批移動（見 4.E）
        └─ draggedShape == null（點空白）：
              canvas.restoreFloating() → canvas.clearSelection() → selectionBox = new Rectangle(startPoint)   // 取消選取＋開始框選
  → canvas.repaint()

拖曳（框選中）   SelectMode.mouseDragged(e)：selectionBox!=null
   → 用 min/abs 算出方框 x,y,w,h → selectionBox.setBounds(...) → repaint
   → SelectMode.draw(g)：填半透明藍 + 藍框                                       // 子功能③：視覺回饋框

放開   SelectMode.mouseReleased(e)：selectionBox!=null
   → for 每個 shape：若 selectionBox.contains(s.getBounds()) → s.setSelected(true)   // 子功能④：完全落入框內才算選到
   → 清 selectionBox/draggedShape/draggedPort → repaint
```

**子功能⑤：選取後顯示 Port**：`BasicObject.draw` 中 `if (selected || hovered)` 才畫出 8/4 個黑色 Port。

**子功能⑥：點選連線**：`ConnectionLine.contains(p)` 用 `Line2D.ptSegDist` 算出滑鼠到線段的最短距離，≤ 5px 就算點中。選取時藍色粗線、懸停時藍色細線。因為連線在清單最前面（最底層），`getTopShapeAt` 從上往下找時會先命中物件，只有點在線「露出來的地方」才會選到線。

**替代流程**

- **Alt C.1**：框選後沒有任何圖形完全落入 → 沒有圖形被選取（等同取消）。
- **Alt C.2**：點到已選取的物件 → 不清除選取（保留多選，供整批移動）。
- **Alt C.3**：點到的是連線 → 照常選取，但 `floatToFront` 發現 `isBackgroundLayer()` 為 true 就不浮起，連線維持在最底層。
- **Alt C.4**：框選範圍完整包住某條連線（兩端都在框內）→ 連線也會被選取。

**涉及函式**：`SelectMode.mouseMoved/mousePressed/mouseDragged/mouseReleased/draw`、`Canvas.getTopShapeAt/clearSelection/floatToFront/restoreFloating`、`Shape.setHovered/setSelected/getBounds`、`BasicObject.draw`（顯示 Port）。

### 4.D 群組 / 解散群組

**功能說明**：把多個圖形包成一個群組（一起移動）；或把群組拆回個別圖形。

**前置條件**：`SelectMode`；透過 Edit 選單觸發。

**主流程（呼叫順序）**

```
群組   Edit→Group → groupItem.actionListener → canvas.groupSelected()
   → selectedShapes = 所有 isSelected() 的圖形，但跳過 isBackgroundLayer() 的連線（並取消其選取）   // 子功能④
   → if selectedShapes.size() >= 2：                       // 子功能①：至少 2 個才成群組
         composite = new CompositeObject()
         for s in selectedShapes：
               s.setSelected(false)
               composite.addComponent(s)                   // → updateBounds()（重算群組包圍盒）
               shapes.remove(s)                            // 從畫布頂層清單移除（改由群組管）
         composite.setSelected(true)
         shapes.add(composite)
         repaint()

解散   Edit→Ungroup → ungroupItem.actionListener → canvas.ungroupSelected()
   → selectedShapes = 所有 isSelected()
   → if size()==1 且 selectedShapes.get(0).isGroup()：     // 子功能②：剛好 1 個且是群組（多型，非 instanceof）
         composite = 該物件
         shapes.remove(composite)
         for child in composite.getComponents()：shapes.add(child)   // 子圖形放回畫布
         repaint()
```

**子功能③：群組包圍盒**：`CompositeObject.updateBounds` 取所有子圖形的 min/max 邊界，算出群組自己的 x,y,width,height（畫虛線外框與點擊判定用）。

**子功能④：連線不進群組**：框選很容易一起選到連線；連線的 x/y/width/height 沒有意義（位置由 Port 決定），若被收進群組，`updateBounds` 會算出錯誤的外框。連線本來就綁在 Port 上，物件被群組後一起移動時線會自動跟著走，不需要群組管理。

**替代流程**

- **Alt D.1**：選取數量 < 2 → `groupSelected` 不做任何事。
- **Alt D.2**：選取不是「剛好 1 個群組」（數量不對或不是群組）→ `ungroupSelected` 不做任何事。

**涉及函式**：`Canvas.groupSelected/ungroupSelected`、`Shape.isSelected/setSelected/isGroup/getComponents`、`CompositeObject.addComponent/updateBounds`。

### 4.E 移動物件（單選＋多選＋群組）

**功能說明**：拖曳已選取的圖形移動位置；多選時一起移動；群組移動時所有成員一起動；連線自動跟隨。

**前置條件**：`SelectMode`；先選取至少一個圖形。

**主流程（呼叫順序）**

```
按下   SelectMode.mousePressed(e)（見 4.C 的 B 分支）
   → 點到未選取物件：clearSelection → setSelected(true) → floatToFront   // 浮到最上層
   → 點到已選取物件：保留多選
   → draggedShape = 該物件；startPoint = 座標

拖曳   SelectMode.mouseDragged(e)：draggedPort==null 且 draggedShape!=null
   → dx = 現在x - startPoint.x;  dy = 現在y - startPoint.y
   → for 每個 isSelected() 的 shape：s.move(dx, dy)        // ★ 子功能①：多選一起移動
   → startPoint = 現在座標
   → canvas.repaint()

放開   SelectMode.mouseReleased(e)：清狀態 → repaint
```

**各種 move 的多型行為**

- `Shape.move`（基底）：`x+=dx; y+=dy`
- `BasicObject.move`：先 `super.move` 再 `updatePorts()`            // 子功能②：Port 跟著移動
- `CompositeObject.move`：對每個子圖形 `move(dx,dy)` 再 `updateBounds()`  // 子功能③：群組成員一起動
- `ConnectionLine.move`：空實作（連線的位置完全由 Port 決定；物件與連線一起被選取拖曳時，線不會被多移一次）

**子功能④：連線自動跟隨**：線本身沒有被移動，但 `ConnectionLine.draw` 即時讀 Port 座標，所以物件一動，連到它的線就自動跟著重畫。

**涉及函式**：`SelectMode.mousePressed/mouseDragged/mouseReleased`、`Canvas.floatToFront`、`Shape/BasicObject/CompositeObject.move`、`BasicObject.updatePorts`、`CompositeObject.updateBounds`。

### 4.F 縮放物件

**功能說明**：拖曳 BasicObject 的 8/4 個 Port 之一改變大小；支援反向拖曳與最小尺寸。

**前置條件**：`SelectMode`；物件處於 selected 或 hovered（才會顯示 Port）。

**主流程（呼叫順序）**

```
按下   SelectMode.mousePressed(e)（最優先檢查 Port）
   → for 每個 (isSelected()||isHovered()) 的 shape：
         p = s.getPortAt(startPoint)
         若 p != null：
               canvas.clearSelection()
               s.setSelected(true)                          // 子功能①：鎖定選取，縮放中 Port 不消失
               draggedPort = p; draggedShape = s
               repaint; return

拖曳   SelectMode.mouseDragged(e)：draggedPort != null
   → draggedShape.resize(draggedPort, mousePoint)           // 多型；只有 BasicObject 真正實作
         → BasicObject.resize：
               index = ports.indexOf(p)（-1 則 return）
               第一次拖曳：鎖定對面邊界為錨點 fixedAnchorX/Y   // 子功能②：固定對邊
               判斷 modifyLeft/Right/Top/Bottom
               minSize = 20；若新尺寸 < 20 → 用最小尺寸推回   // 子功能③：最小尺寸保護
               更新 this.x/width 或 this.y/height（用 min(錨點,目標) 支援反向拖曳）  // 子功能④
               updatePorts()                                // Port 重算
   → canvas.repaint()

放開   SelectMode.mouseReleased(e)：清 draggedPort/draggedShape → repaint
```

**替代流程**

- **Alt F.1**：點到的是 `CompositeObject` 或 `ConnectionLine` → 它們的 `resize` 是空實作（無 Port、不可縮放），拖曳不會改變大小。
- **Alt F.2**：反向拖曳（把右下角拖過左上角）→ 用 `min(錨點,目標)` 重新決定左上角座標，圖形翻面仍正確。
- **Alt F.3**：新尺寸 < 20px → 強制維持 20px。

**涉及函式**：`SelectMode.mousePressed/mouseDragged/mouseReleased`、`Shape.getPortAt`、`Port.contains`、`BasicObject.resize/updatePorts`、`CompositeObject/ConnectionLine.resize`（空實作）。

### 4.G 自訂標籤風格

**功能說明**：改一個基本物件的名稱與顏色（彈出對話框）。

**前置條件**：`SelectMode`；有一個 `BasicObject` 被選取（`canCustomizeLabel()`）。

**主流程（呼叫順序）**

```
點 Edit→Label → labelItem.actionListener → UMLEditor.customizeLabel()
   → target = null
   → for s in canvas.getShapes()：若 s.isSelected() && s.canCustomizeLabel() → target = s; break   // 子功能①：多型挑出可改標籤者
   → 若 target==null → return                                 // 替代流程 Alt G.1
   → nameField = new JTextField(target.getLabel())
   → colorButton = new JButton（顯示 target.getColor()）
        colorButton.addActionListener → JColorChooser.showDialog(...)   // 子功能②：點開調色盤
              選色後更新 selectedColor[0] 與按鈕預覽
   → panel = JPanel(GridLayout) 放入 Name/Color
   → result = JOptionPane.showConfirmDialog(...)               // 阻塞，等使用者
   → 若 result == OK_OPTION：                                  // 子功能③：OK 才套用
         target.setLabel(nameField.getText())
         target.setColor(selectedColor[0])
         canvas.repaint()
```

**子功能④：標籤即時顯示**：`BasicObject.draw` 用 `FontMetrics` 量出文字寬高後置中：`textX = x + (width - stringWidth) / 2`、`textY = y + (height - fontHeight) / 2 + ascent`。（`drawString` 的 y 是文字「基線」而非左上角，所以要加 ascent。）

**替代流程**

- **Alt G.1**：沒有被選取的可改標籤物件 → 直接結束，不彈視窗。
- **Alt G.2**：使用者按 Cancel（或關閉視窗）→ `result != OK_OPTION` → 物件維持原樣。

> 設計重點：對話框（JOptionPane/JColorChooser）屬 UI 層，放在 **UMLEditor**，不是 Canvas。

**涉及函式**：`UMLEditor.customizeLabel`、`Canvas.getShapes`、`Shape.isSelected/canCustomizeLabel/getLabel/setLabel/getColor/setColor`、`Canvas.repaint`、`BasicObject.draw`（畫 label）。

### 4.H 刪除（物件／連線／群組）

**功能說明**：刪除所有選取的圖形；刪除物件時，連在它（含群組內子物件）身上的連線一起刪除，不留下懸空的線。

**前置條件**：`SelectMode`；至少選取一個圖形。

**主流程（呼叫順序）**

```
按 Delete 鍵（或 Edit→Delete）→ deleteItem.actionListener → canvas.deleteSelected()
   → restoreFloating()                                   // 先還原浮起的物件，避免之後記錄的原位失準
   → selectedShapes = 所有 isSelected() 的頂層圖形
   → 若 selectedShapes 為空 → return                     // Alt H.1
   → removedShapes = new HashSet()
   → for s in selectedShapes：collectWithDescendants(s, removedShapes)   // 子功能①：遞迴收集群組子孫
         → result.add(s)
         → for child in s.getComponents()：collectWithDescendants(child, result)
   → shapes.removeAll(selectedShapes)                    // 從畫布移除選取的圖形
   → shapes.removeIf(s -> s.isAttachedToAny(removedShapes))   // 子功能②：清掉依附的連線
         → Shape.isAttachedToAny：預設 false
         → ConnectionLine.isAttachedToAny：起點或終點 Port 的主人在集合中 → true
   → repaint()
```

**子功能①：為什麼要遞迴收集**：連線的 Port 屬於群組「裡面」的 BasicObject，不是群組本身。例如 A、B 群組成 G，C 連到 A；刪除 G 時，集合裡必須有 A，C→A 的線才會被判定為依附。用 `HashSet` 是因為 `contains()` 為 O(1)。

**子功能②：多型查詢取代 instanceof**：`Canvas` 不需要知道誰是連線，只要逐一詢問「你是否依附在被刪除的圖形上？」。

**替代流程**

- **Alt H.1**：沒有選取任何圖形 → 直接結束，連 `repaint` 都不做。
- **Alt H.2**：只選取連線 → 只刪除該連線，物件不受影響。

**涉及函式**：`UMLEditor`（deleteItem、`setAccelerator`）、`Canvas.deleteSelected/collectWithDescendants/restoreFloating`、`Shape.getComponents/isAttachedToAny`、`ConnectionLine.isAttachedToAny`。

### 4.I 存檔 / 讀檔

**功能說明**：把整張圖（物件、群組、連線、標籤、顏色）存成 `.uml` 檔，並可讀回。

**前置條件**：任何模式皆可；透過 File 選單或 Ctrl+S / Ctrl+O 觸發。

**主流程（呼叫順序）**

```
存檔   File→Save（Ctrl+S）→ UMLEditor.saveDiagram()
   → file = chooseFile(true, "UML Diagram (*.uml)", "uml")
         → JFileChooser + FileNameExtensionFilter → showSaveDialog（模態，等待使用者）
         → 沒有副檔名 → 自動補上 ".uml"                 // 子功能①
         → 檔案已存在 → JOptionPane 確認覆寫            // 子功能②
   → 若 file == null → return                           // 使用者取消
   → DiagramFileIO.save(file, canvas.getShapes())
         → try-with-resources 開啟 ObjectOutputStream(BufferedOutputStream(FileOutputStream))
         → out.writeObject(new ArrayList<>(shapes))      // ★ 整個清單「一次」寫出

讀檔   File→Open（Ctrl+O）→ UMLEditor.openDiagram()
   → file = chooseFile(false, ...) → showOpenDialog
   → DiagramFileIO.load(file)
         → ObjectInputStream.setObjectInputFilter(LOAD_FILTER)   // ★ 子功能③：白名單
         → data = readObject()
         → 驗證 data 是 List，且每個元素都是 Shape        // 子功能④：外部輸入驗證
   → canvas.replaceAllShapes(list)
         → shapes.clear() → shapes.addAll(list)          // 檔案中的順序就是 z-order
         → 清掉 floatingShape / floatingSavedIndex
         → 所有圖形（含群組子孫）setSelected(false) / setHovered(false)
         → repaint()
```

**為什麼要「一次」writeObject**：Java 序列化在同一次寫入中會記住寫過的物件，同一個物件第二次只寫參照編號。所以讀回來後，`ConnectionLine` 參照的 Port 與 `BasicObject` 持有的 Port 仍是**同一個物件**，拖曳物件時連線依然會跟著走。

**子功能③：白名單（`ObjectInputFilter`，JDK 9+）**：只允許 `shape.*`、`java.util.*`、`java.lang.*`、`java.awt.Color`，其餘一律拒絕；另限制巢狀深度、參照數量與檔案大小。用來防範惡意檔案在反序列化過程中觸發危險類別（Java 反序列化漏洞）。

**子功能④：外部輸入驗證**：這裡用 `instanceof` 並不違反專案慣例。慣例針對的是「依型別決定行為」（應改用多型）；這裡是「驗證不可信任的外部資料」，必須在轉型前確認型別。

**替代流程**

- **Alt I.1**：使用者在對話框按 Cancel → 不做任何事。
- **Alt I.2**：覆寫確認選「否」→ 不存檔。
- **Alt I.3**：檔案不是本程式存的、已損毀、或含白名單外的類別 → 丟出例外 → `showError` 顯示「讀檔失敗」，畫布維持原狀。

**涉及函式**：`UMLEditor.saveDiagram/openDiagram/chooseFile/showError`、`DiagramFileIO.save/load`、`Canvas.getShapes/replaceAllShapes/allShapesIncludingDescendants`。

### 4.J 匯出 PNG

**功能說明**：把整張圖匯出成 PNG 圖片，圖片中不含控制點、選取高亮與模式的暫時 UI。

**前置條件**：任何模式皆可；透過 File→Export PNG 或 Ctrl+E 觸發。

**主流程（呼叫順序）**

```
File→Export PNG（Ctrl+E）→ UMLEditor.exportPng()
   → file = chooseFile(true, "PNG Image (*.png)", "png")
   → image = canvas.renderToImage()
         → 影像寬高 = max(畫布大小, 所有圖形最右/最下邊界 + 20)     // 子功能①：圖形超出畫布也完整匯出
         → image = new BufferedImage(w, h, TYPE_INT_RGB)
         → g2 = image.createGraphics()
         → g2 塗滿白色背景                                         // 新建的 BufferedImage 預設全黑
         → 記住誰是 selected / hovered → 全部清除                  // 子功能②：不畫控制點與高亮
         → drawAllShapes(g2)                                      // 與螢幕繪製共用，兩輪（本體＋前景層）
         → 還原 selected / hovered 狀態
         → finally：g2.dispose()                                  // 自己 create 的畫筆要自己釋放
   → DiagramFileIO.exportPng(file, image)
         → ImageIO.write(image, "png", file)；回傳 false 時丟出 IOException
```

**重點**：`Shape.draw(g)` 完全不用修改就能畫進影像，因為 `BufferedImage.createGraphics()` 給的也是同一套 `Graphics` API——畫在螢幕還是記憶體中的影像，對 `draw` 來說沒有差別。另外匯出時**不呼叫** `currentMode.draw()`，所以預覽框、框選框不會出現在圖片裡。

**替代流程**

- **Alt J.1**：使用者按 Cancel 或拒絕覆寫 → 不匯出。
- **Alt J.2**：寫檔失敗 → `showError` 顯示「匯出失敗」。

**涉及函式**：`UMLEditor.exportPng/chooseFile/showError`、`Canvas.renderToImage/drawAllShapes/allShapesIncludingDescendants`、`DiagramFileIO.exportPng`。

## 5. 兩個關鍵設計機制

### 5.1 一次性動作自動回 Select（方案 B：預設模式 + 模式變更事件）

```
建立物件/連線的 mouseReleased 最後一行
  → canvas.returnToDefaultMode()
        → setCurrentMode(defaultMode = selectMode)
              → currentMode = selectMode
              → modeListener.onModeChanged(selectMode)        // 事件
                    → UMLEditor.highlightActiveButton(selectMode)   // Select 按鈕換黑色粗框
```

好處：「使用者點按鈕」與「畫完自動回 Select」**共用同一條** `setCurrentMode → onModeChanged → highlightActiveButton`，按鈕高亮邏輯只有一份；Canvas 透過介面通知，不需 import UMLEditor（維持單向依賴）。

### 5.2 z-order：浮起與還原

```
點到未選取物件 → canvas.floatToFront(shape)
      → restoreFloating()（先還原上一個）
      → floatingSavedIndex = shapes.indexOf(shape)   // 記原位
      → bringToFront(shape)                          // 移到清單末端＝最上層

點空白 / 改點別的 → canvas.restoreFloating()
      → 若 floatingShape 仍在清單：移除並插回 floatingSavedIndex（還原層數）
      → 清空浮起狀態
```

z-order 的唯一真理就是 `shapes` 清單順序（越後面越上層），所以 `paintComponent` 不必每幀排序。
